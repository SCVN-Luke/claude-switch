CLAUDE SWITCH
Switch Claude Desktop between several accounts in a few clicks.
Unofficial tool, not made by or affiliated with Anthropic.

================================ ENGLISH ================================

Requirements: macOS 14 or later, Claude Desktop installed in /Applications.

Install
  1. Drag ClaudeSwitch.app onto the Applications folder in this window.
  2. Open ClaudeSwitch from Applications.
     The app is not notarized by Apple, so macOS blocks the first launch:
       - Click "Done" (or "OK") on the warning.
       - Open System Settings › Privacy & Security, scroll down and click
         "Open Anyway" next to ClaudeSwitch, then confirm.
     Or run this once in Terminal:
       xattr -dr com.apple.quarantine /Applications/ClaudeSwitch.app
  3. A two-people icon appears in the menu bar. The Guide opens on first run
     (menu › Guide… opens it again). The language can be changed with the
     globe button in the menu.
  4. When macOS asks to use "Claude Safe Storage" in your keychain, choose
     "Always Allow" — this lets the app show your current usage.

Privacy: to show usage, the app reads Claude Desktop's sign-in cookie on
your Mac and sends it only to claude.ai. Nothing is stored or sent elsewhere.

================================ TIẾNG VIỆT ================================

Yêu cầu: macOS 14 trở lên, đã cài Claude Desktop trong /Applications.

Cài đặt
  1. Kéo ClaudeSwitch.app vào thư mục Applications trong cửa sổ này.
  2. Mở ClaudeSwitch từ Applications.
     App chưa được Apple notarize nên macOS sẽ chặn lần mở đầu tiên:
       - Bấm "Done" (hoặc "OK") ở cảnh báo.
       - Mở System Settings › Privacy & Security, kéo xuống, bấm
         "Open Anyway" cạnh ClaudeSwitch rồi xác nhận.
     Hoặc chạy lệnh này một lần trong Terminal:
       xattr -dr com.apple.quarantine /Applications/ClaudeSwitch.app
  3. Icon hình hai người xuất hiện trên thanh menu. Hướng dẫn tự mở ở lần
     chạy đầu (menu › Hướng dẫn… để mở lại). Đổi ngôn ngữ bằng nút quả địa
     cầu trong menu.
  4. Khi macOS hỏi quyền dùng "Claude Safe Storage" trong keychain, chọn
     "Always Allow" — để app hiện được usage hiện tại.

Riêng tư: để hiện usage, app đọc cookie đăng nhập của Claude Desktop trên
máy bạn và chỉ gửi nó tới claude.ai. Không lưu hay gửi đi đâu khác.

================================ 한국어 ================================

요구 사항: macOS 14 이상, /Applications에 Claude Desktop 설치.

설치
  1. 이 창에서 ClaudeSwitch.app을 Applications 폴더로 드래그하세요.
  2. Applications에서 ClaudeSwitch를 여세요.
     Apple 공증을 받지 않은 앱이라 macOS가 처음 실행을 차단합니다.
       - 경고 창에서 "완료"(또는 "확인")를 클릭하세요.
       - 시스템 설정 › 개인정보 보호 및 보안에서 아래로 스크롤하여
         ClaudeSwitch 옆의 "그래도 열기"를 클릭하고 확인하세요.
     또는 터미널에서 다음 명령을 한 번 실행하세요:
       xattr -dr com.apple.quarantine /Applications/ClaudeSwitch.app
  3. 메뉴 막대에 두 사람 모양 아이콘이 나타납니다. 처음 실행 시 가이드가
     열립니다(메뉴 › 사용 가이드…로 다시 열기). 메뉴의 지구본 버튼으로
     언어를 바꿀 수 있습니다.
  4. macOS가 키체인의 "Claude Safe Storage" 사용을 물으면 "항상 허용"을
     선택하세요. 그래야 현재 사용량이 표시됩니다.

개인정보: 사용량을 표시하기 위해 앱은 Mac에 있는 Claude Desktop의 로그인
쿠키를 읽고 claude.ai로만 보냅니다. 다른 곳에 저장하거나 보내지 않습니다.
